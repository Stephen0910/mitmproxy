# mitmproxy.flow 模块

此模块包含表示网络流量的基本类。Flow（流量）是mitmproxy拦截的所有网络通信的基本单位。

以下是一些重要的类和组件：

- **Flow**: 所有流量类型的基类
- **Error**: 表示在流量处理过程中发生的错误

您可以在插件开发中使用这些类来访问和修改流量信息。
