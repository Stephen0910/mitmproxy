# 用户界面

首先，我们需要熟悉mitmproxy的用户界面。
打开您启动mitmproxy的终端窗口。
您现在处于mitmproxy的默认视图，它显示了流量列表。
您应该能看到浏览器加载本教程的HTTP请求。
当新请求进入时，mitmproxy会向视图中添加行。
